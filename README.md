✨ GenZ Hub - Social Media Onboarding & Feed Simulation
GenZ Hub is a single-file web application that simulates the onboarding process and primary feed experience of a modern, GenZ-focused social media platform, heavily inspired by the Instagram interface and aesthetics.

🌟 Overview
The definitive social platform for digital natives. Enjoy a sleek dark mode with vibrant fuchsia/violet aesthetics. Quick 3-step onboarding & Vibe Personalization. Get an authentic, visually-rich feed where your vibe defines the experience.

🚀 Features
3-Step Onboarding Flow: Guides the user through Sign Up, Profile Personalization, and Connection setup.

Aesthetic UI: Uses a modern dark-mode color palette (genz-primary: #f0abfc, genz-secondary: #8b5cf6).

Instagram Clone: The final view is a simulated feed, complete with a Stories bar, stylized top navigation (GenZ Hub logo), and realistic post structures.

Functional Navigation: All primary navigation buttons (Home, Explore, Create, Shop, Profile, Messages) are linked to a JavaScript handler that simulates view changes.

Fully Responsive: Designed with a mobile-first approach using Tailwind CSS to ensure excellent display on small devices.

💻 Technology Stack
This is a self-contained, client-side application built for maximum portability:

HTML5: Structure of the application.

Tailwind CSS: Used for all styling and responsive utility classes (loaded via CDN).

JavaScript (Vanilla JS): Manages the multi-step state and handles all DOM manipulation and simulated navigation.

Font Awesome: Used for various social media icons (like, comment, share, nav icons).

🔧 How to Run
Since this is a single, self-contained HTML file, running the application is extremely simple:

Save the file: Save the entire code block as index.html.

Open in Browser: Double-click the index.html file.

The application will launch immediately in your default web browser. No server, dependencies, or build steps are required.
